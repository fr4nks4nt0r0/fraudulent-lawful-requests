# Metodologia

1) SCOPO

L'obiettivo è rendere ogni valutazione riproducibile, applicando le stesse regole alle stesse fonti deve arrivare allo stesso risultato.

---------

2) SISTEMA DI VALUTAZIONE (Admiralty)

Ogni affermazione riceve due voti indipendenti: uno sulla fonte, uno sull'informazione.

AFFIDABILITÀ DELLA FONTE

|	Voto	|	Significato	|	Esempio	|
|--- |--- |--- |
|	A	| Completamente affidabile | Atto giudiziario pubblico |
|	B	| Di solito affidabile | Comunicato ufficiale di un ente o azienda |
|	C	| Abbastanza affidabile | Testata nazionale con fonti anonime |
|	D	| Di solito non affidabile | Blog che riprende altri senza verifiche |
|	E	| Inaffidabile | L'attore stesso |
|	F	| Non valutabile | Fonte nuova o sconosciuta |

CREDIBILITÀ DELL'INFORMAZIONE

|	Voto	|	Significato	|
|--- |--- |
|	1	| Confermata da altre fonti indipendenti |
|	2	| Probabilmente vera |
|	3	| Possibilmente vera |
|	4	| Dubbia |
|	5	| Improbabile |
|	6	| Non valutabile |

Notare i due voti sono indipendenti, una fonte inaffidabile può dire una cosa vera (E1), e una fonte affidabile può sbagliare (B4).

---------

REGOLE DI APPLICAZIONE

1-	Si valuta la fonte per ogni affermazione, non la testata, se un giornale riporta ciò che gli ha detto l'attore la fonte è quest ultimo ed il giornale fa da tramite.
2-	L'attore ha come massimo E, avendo interesse a gonfiare le proprie capacità per aumentare la pressione estorsiva.
3-	Chi parla di sé ha un conflitto di interessi, LE DICHIARAZIONI DI QUESTO TIPO SARANNO SEGNATE COME TALI.
4-	Più articoli che citano la stessa fonte valgono come una sola fonte.
5-	Si cita sempre la fonte primaria, Se un articolo riprende un altro
   articolo, si risale all'originale.
6-	Le contraddizioni si registrano E Le incoerenze dell'attore sono di per sé un dato di analisi.
7-	Ogni affermazione è datata, lo stato può cambiare nel tempo, il registro indica quando è stata fatta e quando è stata verificata.

---------

STATI DI VERIFICA

|	Stato	|	Quando	|
|--- |--- |
| CONFERMATO_UFFICIALE | Confermato da un ente pubblico o dall'organizzazione coinvolta |
| CONFERMATO_INDIPENDENTE | Confermato da almeno due fonti indipendenti tra loro |
| RIPORTATO_NON_CONFERMATO | Riportato dalla stampa, senza conferma ufficiale né indipendente |
| RIVENDICATO | Affermato solo dall'attore della minaccia |
| CONTRADDETTO | Esistono versioni incompatibili tra loro |
| SMENTITO | Negato con evidenze da una fonte affidabile |
